# VM – Domain Controller

## Aufgabe

Der Domain Controller stellt zentrale Windows-Domain-Dienste für die Umgebung bereit.

### Funktionen

- Active Directory
- Benutzerverwaltung
- Gruppenverwaltung
- DNS

Die Clients können dadurch zentral verwaltet und in die Domäne integriert werden.
