# VM – Bla

## Übersicht

Diese Seite dokumentiert die virtuelle Firewall **FW-OPSense**.

| Parameter | Wert |
|---|---|
| VM-ID | 101 |
| SSH-Nickname | ops |
| VM-Name | FW-OPSense |
| Zweck | Firewall / Router |
| Betriebssystem | OPNsense |
| IPv4 | nicht angegeben |
| Größe | 20 GB |
| RAM | 4 GB |
| vCPU | 2 |

## Aufgaben

Die Firewall übernimmt die zentrale Netzwerkfunktion innerhalb des Home Labs.

Dazu gehören insbesondere:

- Routing zwischen den Netzwerksegmenten
- Filterung von Verbindungen
- Zugriffskontrolle
- Trennung von Infrastruktur-, Server- und Client-Netz
- zentrale Netzwerkverwaltung

## Netzwerk

Die Firewall stellt die Verbindung zwischen den definierten Netzwerksegmenten her und kontrolliert den Datenverkehr zwischen ihnen.
