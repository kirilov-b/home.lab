# VM – Testclient CL1

## Übersicht

Diese Seite dokumentiert die virtuelle Maschine **CL1-WC-30**.

**VM Parameter**

| Parameter      | Wert       |
| -------------- | ---------- |
| VM-ID          | 301        |
| SSH-Nickname   | cl1        |
| VM-Name        | cl1-wc-30  |
| Zweck          | Testclient |
| Betriebssystem | Windows 11 |
| IPv4           | DHCP       |
| Domain         | lab.home   |
| Größe          | 60 GB      |
| RAM            | 6 GB       |
| vCPU           | 2          |

## Überblick

Der Testclient wird für Tests innerhalb der Laborumgebung verwendet.

Dazu gehören beispielsweise:

- Prüfung der Netzwerkverbindung
- DNS-Tests
- Tests von Firewall-Regeln
- Überprüfung von zentralen Diensten
- Validierung von Benutzer- und Domänenfunktionen
