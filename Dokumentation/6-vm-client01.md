# VM – CLIENT01

## Aufgabe

CLIENT01 dient als Beispiel für ein in die Windows-Domäne integriertes Client-System.

### Konfiguration

- Windows Client
- Domänenmitglied
- Netzwerkzugriff über die Firewall
- DNS über den Domain Controller

Der Client wird für Tests und zur Überprüfung der zentralen Dienste verwendet.
